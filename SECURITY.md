# Segurança

Use a aba **Security** do GitHub para enviar um relato privado de vulnerabilidade, se a opção estiver habilitada. Se não estiver disponível, abra uma issue sem incluir senhas, tokens, dados pessoais ou arquivos de estado.

O app lê senha SMTP de variável de ambiente ou arquivo local. Não envie credenciais em issues, pull requests ou logs.
